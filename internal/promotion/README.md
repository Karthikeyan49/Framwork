# Immutable release contracts — M6R

Candidate bundles bind source/IR/version/base/dependency/intent/acceptance/sandbox/
verification hashes. Build and stored Restore share integrity/admission checks without
production recompilation. Trusted Gate ports, exact approvals, immutable database
artifacts, CAS activation and assessed pointer rollback are tested foundations.

Store methods belong inside WithRuntime and append audit before commit. No HTTP
production endpoint exists. The future trusted verifier must execute acceptance and
attest report provenance; declaring PASS in a payload is not a production capability.
Sandbox manager, candidate orchestration and approval services are M11/M12/M13.
Operator release-check rejects unsupported active IR before deployment. See ADR-020.
