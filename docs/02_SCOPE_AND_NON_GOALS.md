# V1 Scope

## Must have
Multi-tenancy; auth; RBAC/ABAC; RLS; metadata entities/fields/relationships/pages; dynamic CRUD; rules; workflows; tool registry; audit; outbox; sandbox; promotion; immutable versions; rollback pointer; AI structured draft builder; observability; export.

## Explicit non-goals
- arbitrary user source-code execution
- universal programming language
- Kubernetes requirement
- many microservices
- full BPMN engine
- automatic destructive migrations
- autonomous high-risk finance actions
- Rust/Python services without measured need
