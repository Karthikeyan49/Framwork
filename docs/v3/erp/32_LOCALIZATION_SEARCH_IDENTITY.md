# Localization, Search, Identity and Residency

## Localization
Metadata labels use localizable keys/resources.

## Search
Start with PostgreSQL full-text search. Add an external search engine only after measured need.

## Enterprise identity
Support adapters for OIDC, SAML and SCIM rather than inventing authentication protocols.

## Data residency
Tenant may have a home region governing DB, object storage, backup, telemetry and AI-processing route.
